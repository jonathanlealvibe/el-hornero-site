# el Hornero — ordering site

React + Vite recreation of the El Hornero ordering site (home, category catalogue, cart drawer),
with the GoHighLevel Voice AI widget loaded from `index.html`.

- `npm run dev` — local dev server
- `npm run build` — production build to `dist/`
- Deploys automatically to GitHub Pages on push to `main` (see `.github/workflows/deploy.yml`),
  served at https://elhornero.conciergeai.space

Design source and client artwork live in `design_handoff_el_hornero_ordering/`.
GoHighLevel IDs and setup notes: `GHL-SETUP.md`.
